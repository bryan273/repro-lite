# Project Summary
Repro Lite helps students and researchers test a specific research claim. It plans a test, writes and runs Python in the visitor’s browser, then reports whether the result matches the claim. Python runs with Pyodide in a Web Worker; user code is not executed on the server.

Completed checks can be saved to a public history gallery. Verdicts use fixed rules, with an AI audit to flag potential issues. The interface supports English and Chinese, light and dark themes, and downloadable Markdown reports. Its refreshed Repro Suite-style layout provides a responsive sidebar for app navigation and links to other suite tools.

# Project Module Description
- **Claim entry and examples:** Enter a research claim, optional paper link, and tolerance; choose an example based on a built-in scikit-learn dataset.
- **Agent workflow:** Plan the test, write and run code, perform a clean rerun, audit the approach, and display a verdict. Progress and tool output appear in a live timeline.
- **Browser Python runner:** Runs code with Pyodide in a Web Worker, with a limit of 10 agent turns and 60 seconds per code run.
- **Verdict, saving, and reports:** Compare measured and target values using fixed rules. Save completed checks, show save status and errors, allow retry, and download a Markdown report.
- **History:** Store completed checks in the Atoms Cloud database and display them in the Recent checks gallery.
- **Authentication and account modules:** Backend routes and services provide authentication, user, and settings functionality.
- **Navigation and responsive shell:** A 248px sidebar links to New check and Recent checks, plus external Repro Suite apps. Below 900px, a slim top bar opens the sidebar as a drawer.
- **Localization and theme:** The English and Chinese switch remains available. Light and dark themes use the Repro Suite palette; the selected theme is saved in local storage under `repro.theme2`.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn-style UI components.
- **Browser computation:** Pyodide in a Web Worker; NumPy, pandas, SciPy, and scikit-learn.
- **AI:** LLM gateway using OpenAI-compatible chat messages and tool calls.
- **Backend:** Python, FastAPI, SQLAlchemy, Alembic.
- **Persistence:** Atoms Cloud database.
- **Testing and quality:** Playwright, ESLint, and frontend plugin tests.
- **Typography:** Inter, Noto Sans SC, and JetBrains Mono.

# Usage
- **Frontend dependencies:** From `app/frontend`, run `npm install`.
- **Frontend development:** Run `npm run dev`.
- **Frontend production build:** Run `npm run build`.
- **Backend dependencies:** From `app/backend`, run `pip install -r requirements.txt`.
- **Backend development:** Run `uvicorn main:app --reload` from `app/backend`.
- **Combined startup:** Use `bash app/start_app_v2.sh` where the project environment supports the startup helper.
- The first browser-side Python run downloads its scientific Python packages and may take up to a minute. No API key is required in the frontend.
